How to use

This page is a starting point. Fill it in as you like.

Setting up (once)

  1. Have RuneLite installed (CS4452 Play uses its Java). The Jagex launcher is fine.
  2. On the Downloads page, sign in and download CS4452-Setup.cmd. Run it and press Enter.
  3. Double-click CS4452 Play on your Desktop. It is a separate RuneLite: your normal one is left alone. The CS4452 plugins are in its plugin list, switched off until you tick one.

Windows may say "Windows protected your PC": click More info, then Run anyway.

Running a plugin

  • Each plugin has its own settings (the wrench next to it). Read the top section first.
  • Run the bot starts it. The pause key (` by default) pauses and resumes the one you last started.
  • Stand where the plugin's description says to start, with the right things in your bag or bank.
  • Running out of a required item ends the run and logs out.

Updates

When RuneLite starts, the CS4452 Updater checks for a new version and downloads it. A message says "restart RuneLite to use it". That's all.

Removing it

Run the installer again and press U. RuneLite is back to how it was.

Logs

The plugins send their own log lines (not chat, not your bank, no account names) so problems can be fixed. They are deleted after 3 days. The CS4452 Updater plugin's settings can switch this off.
